## 1. Mary K. Greer《塔罗解牌大师21秘技》（21 Ways to Read a Tarot Card）
**定位：进阶 · 融入牌阵解读（也适用于单张牌深挖）**

### 核心理念
- **R.I.T.E.：互动式转化赋权解读法**（Reading Interactively for Transformation and Empowerment）
- 主张：**从单张随机抽的牌出发**，用21种方法层层深挖 —— 一张牌能挖出和整个牌阵一样多的信息
- 解读者是"灵魂的助产士"：用技巧提问，让问卜者自己"孕育"出答案，而非替对方解决问题
- 每种方法分**两级**：**新手之道（Aces）**、**行家之道（Adept）**
- 21种是"百宝袋"，可自选、混搭出个人解读风格；多数解读只用其中几个

### 完整 21 步（已核实）
| # | 名称 | 一句话 |
|---|------|--------|
| 0 | 勇敢跨出第一步 | 准备：选定一张牌作为核心 |
| 1 | 名称 | 说出牌名（看似平淡但关键） |
| 2 | 描述 | 客观、字面描述牌面（全书最重要，一切基础） |
| 3 | 情绪 | 牌面人物/自己的情绪反应，情绪↔图像互相转化 |

## 2. 丹尼尔《学会塔罗的16堂课》（珍藏版）
**定位：基础（牌意/结构）→ 融入牌意学习；进阶（牌阵）→ 融入牌阵解读**

### 完整目录（已核实，16课/4部）
- **第一部 塔罗牌概述**：1歷史與四大功能 / 2占卜基本概念（占卜概論·基本流程·禁忌）/ 3基本結構
- **第二部 牌義解釋**：4權杖 / 5聖杯 / 6寶劍 / 7錢幣 / 8宮廷牌 / 9-11大牌一二三
- **第三部 塔羅牌理論**：12色彩象徵 / 13占星連結 / 14數字結構 / **15牌陣理論與經典牌陣**
- **第四部 結論**：16對學習者的叮嚀（使用保護·占卜心態·塔羅日記·更進一階）

### 第3课 · 塔罗牌设计的三层结构（基础）
- 78张 = 两部分、三种牌：大牌22（抽象理念）+ 宫廷16（人物）+ 数字牌40（4花色×10）
- **大牌塔罗方阵**：大牌排成方阵，以正义为轴心，上下左右对称，两张牌数字相加=22（正义的两倍）
- 愚人的特殊地位：超出规则之外，可出现在任何位置，无固定顺序

### 第15课 · 牌阵理论（进阶，核心方法）★
**牌阵的四个分析单元**（每个牌阵都可拆成这四块）：
1. 目的及使用时机　2. 使用张数　3. 图形及位置　4. 解释的逻辑及方式

**牌阵按目的分四大类**：
- **时序类**：按时间发展分析（如"时间之流牌阵"）
- **状况类**：分析一个现实/假设状况的各部分（如"四要素牌阵"）
- **选择类**：比较多个选项（如"二择一牌阵"）
- **混合类**：前三类混合（进阶，书中不举例）

**如何学习使用牌阵**：
1. **选定少量牌阵精修**："精不在多"；从时序/状况/选择三类各选一个，3个牌阵即可应对多数状况；张数从3-5张起步
2. **练习固定方式解牌**：熟能生巧；别用太多花招，用简单固定流程+依循一定逻辑，按部就班把每张牌解释完整；不要依赖灵感突发奇想（否则没灵感时被打回原形）

**串牌成故事的示范（解牌顺序范例，感情三角）**：
- 切牌=正义→当事人心态（希望公平、犹豫不决）
- 过去=钱币三→过去关系稳定
- 现在=宝剑十→剧变、刚提分手
- 未来=宝剑三→若不变将陷入伤心
- **整体分析与建议**：观察"整个牌阵没出现圣杯牌"→感情成分已不重；把各位置串成因果故事线，落到具体建议（当机立断、清洗净化后迎新）
- ⇒ 方法精髓：**按位置逐张定义 → 观察缺失花色/因果流动做整体分析 → 落地成具体建议**

### 四要素牌阵（状况类，4张）示例结构
- 位置：①火要素 ②土要素 ③风要素 ④水要素 + 切牌（主观心态）+ 建议
- 标准化呈现：类别/使用张数/使用时机/图形及位置

## 3. 丹尼尔《塔罗解牌字典》
**定位：基础 · 融入牌意学习（强化牌意落地到具体问题）**

### 编写依据（已核实，作者序）
- 以标准伟特牌为蓝本
- 主要为丹尼尔自己占卜经验，配合：Mathers《The Tarot》、Waite《The Pictorial Key to the Tarot》、黄金黎明标准讲义《The Book "T"》（收录于 Regardie《The Golden Dawn》）

### 核心理念（书页7"塔罗牌义的基本性质"）★
- 78张牌是一个**分类系统**，能把所有概念/人物/事件包含进去 → 每张牌涵义非常丰富
- **批评"关键字系统"**：简化成关键字虽方便，但会让人以为"牌义只有这些"、画地自限
- **主张把牌义视为"类别"概念**：除书上"定义"外，实际占卜可代表不同涵意，人人可发展自己的用法
- ⇒ 正好呼应用户核心痛点：别把牌义框死在关键字，要当可延展的类别落到实际问题

### 词条编排结构（书页22"皇后正位"为例，已核实）
- 每张牌分**正位/逆位**两条目
- 每条目按**具体问题情境**分块给解读，例如：
  - 《人物》：当事人的个性 / 工作观 / 感情观 / 金钱观 / 与当事人应对方法 / 人物代表
  - 《工作》：工作本身状况 / 如何解决困境 / 工作中人际 / 与上司相处 / 发展性 / 找/换工作
  - 《心灵与精神层面的提示》等
- ⇒ 本质是 **"牌 × 具体问题情境" 的查询式工具书**，与网站现有 applications(career/love/self/money) 高度一致，可扩展更细的问题维度
